# Инструкция для жюри

Backend и frontend — один сервис на FastAPI, без отдельного React/Node.
Дашборд отдаётся тем же процессом, что и API.

## Требования

Только Docker (и Docker Compose — идёт в комплекте с Docker Desktop
на Windows/Mac, на Linux ставится отдельно как `docker-compose-plugin`).
Python и другие зависимости на компьютере жюри ставить не нужно — всё
собирается внутри контейнера.

## Запуск

1. Склонировать репозиторий и перейти в его папку:
   ```
   git clone <ссылка на репозиторий>
   cd tram-backend
   ```

2. Собрать образ и запустить сервис одной командой:
   ```
   docker compose up --build
   ```
   Первая сборка занимает 1-2 минуты (скачивание базового образа Python
   и установка зависимостей). Повторные запуски (`docker compose up`,
   без `--build`) — за секунды.

3. Открыть в браузере: **http://localhost:8000**

4. Остановить сервис: `Ctrl+C` в том же терминале, либо в другом
   терминале `docker compose down`.

Если порт 8000 на компьютере жюри уже занят другим приложением — поменять
левое число в `docker-compose.yml`, в строке `"8000:8000"`, например на
`"8080:8000"`, и открывать `http://localhost:8080`.

## Ключевые эндпоинты API

Все эндпоинты — `GET`-запросы, отдают JSON (кроме `/export/*`, там файл).
Автоматическая интерактивная документация со всеми параметрами доступна
на **http://localhost:8000/redoc** сразу после запуска.

| Эндпоинт | Что делает | Пример |
|---|---|---|
| `GET /forecast` | Прогноз с фильтрами: маршрут, диапазон дат, час | `/forecast?route=1&date_from=2025-11-01&date_to=2025-11-01&hour=8` |
| `GET /forecast/routes` | Список всех маршрутов со сводкой по каждому | `/forecast/routes` |
| `GET /geo/routes-with-map` | Список маршрутов, для которых есть география | `/geo/routes-with-map` |
| `GET /geo/route/{route}` | Координаты остановок маршрута по направлениям | `/geo/route/7` |
| `GET /events/applied` | Какие календарные/событийные поправки уже учтены моделью для даты и маршрута | `/events/applied?route=7&date_from=2025-11-13&date_to=2025-11-13` |
| `GET /export/csv` | Выгрузка отфильтрованного прогноза в CSV | `/export/csv?route=1&date_from=2025-11-01&date_to=2025-11-30` |
| `GET /export/xlsx` | То же самое в Excel | `/export/xlsx?route=1&date_from=2025-11-01&date_to=2025-11-30` |
| `GET /health` | Проверка, что сервис жив (для мониторинга) | `/health` |

Параметры `route`, `date_from`, `date_to`, `hour` необязательны — без них
эндпоинт вернёт данные по всем маршрутам/датам/часам целиком.
