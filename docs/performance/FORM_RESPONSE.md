# Ответ для формы

Проведён локальный HTTP-нагрузочный тест backend на MacBook Air M2, 8 ядер/8 GB RAM, Python 3.13.5, FastAPI + Uvicorn, один worker. Всего выполнено 9 650 запросов, ошибок — 0. Смешанный рабочий сценарий (прогноз дня, список маршрутов, события и геоданные): 646 RPS, p50 78,6 мс, p95 97,3 мс, p99 109,3 мс при 50 параллельных запросах. Полная выдача всех 14 640 прогнозных строк: 64,8 RPS, p95 93,1 мс при конкурентности 5. Экспорт CSV: p95 63,2 мс; XLSX: p95 119,6 мс. Пиковое потребление памяти в серии тестов — 172,3 MB. Данные загружаются в RAM один раз при старте; замеры и воспроизводимый скрипт находятся в `docs/performance/` и `tests/load_test.py`.

Дополнительные возможности: интерактивный web-дашборд; фильтрация по маршруту, дате, периоду и часу; горизонты день/месяц/весь прогнозный период; графики, таблица и агрегаты; сценарий «что если» для мероприятий и ограничений движения; пояснение уже учтённых моделью календарных и транспортных событий со ссылками на источники; карта остановок и обоих направлений для маршрутов с доступной географией; экспорт CSV/XLSX; Swagger/OpenAPI; health-check; CORS; автоматическая проверка схемы данных и понятные ошибки API.
