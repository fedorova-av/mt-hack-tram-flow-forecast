# Внешние данные финального решения v3

Эта папка подготовлена для обязательного поля:

> «Ссылка на все внешние данные, использованные в решении (трафик, погода, календарь, новости и др.)»

После загрузки папки в публичный GitHub-репозиторий в форму можно вставить ссылку непосредственно на неё.

## Содержимое

- [`external_sources.md`](external_sources.md) — основной человекочитаемый перечень источников и способов использования;
- [`external_sources.csv`](external_sources.csv) — машиночитаемый реестр со статусом каждого источника;
- [`calendar_and_events_v3.json`](calendar_and_events_v3.json) — даты и правила, фактически использованные в финальном v3.

## Важное разграничение

- `used` — источник действительно влияет на финальный v3;
- `confirmation_only` — источник подтверждает факт, уже присутствующий в датасете;
- `tested_not_selected` — источник исследовался, но не меняет финальный прогноз.

Финальный вариант модели: `v3-main-t1-0.90`. Погода и дорожный трафик в него **не входят**. Сырые внешние выгрузки для инференса не требуются: использованные календарные и транспортные факты зафиксированы в JSON и в коде модели.

Все поправки уже включены в итоговый `submission.csv`; повторно применять их на стороне дашборда не нужно.
