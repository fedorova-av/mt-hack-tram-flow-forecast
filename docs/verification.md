# Проверка локальной поставки

Дата: 27.09.2026. Основа: коммит `84915f5` репозитория `fedorova-av/mt-hack-tram-flow-forecast`. Среда: Windows 11, Python 3.12.14; зависимости установлены из `backend/requirements.txt` в отдельное окружение.

## Исправления

- Backend загружает `backend/data/submission.csv`. Пути к данным, статике и документации вычисляются от `__file__`.
- Документы проекта доступны по `/project-docs/`; Swagger сохраняет `/docs`. Исправлена ссылка на реестр источников в дашборде.
- Dockerfile копирует приложение и данные из `backend/`, документацию — из корневого `docs/`. Docker-контекст исключает исследовательские данные и архивную копию приложения.
- Границы месяца в интерфейсе вычисляются по местному календарю без сдвига на предыдущие сутки.
- API проверяет даты, порядок границ и диапазон часов. Некорректные запросы возвращают 422.
- В основной backend перенесена векторизованная сериализация прогноза из нагрузочной версии. Добавлена проверка значений CSV до сериализации.
- Переводы строк финального submission закреплены как LF в Git и при инференсе: SHA-256 воспроизводится на Windows.
- Добавлена папка `data_preparation/` с реальным скриптом аудита и инструкцией; обновлены README и устаревшие сведения о составе поставки.

## Как повторить

Из корня репозитория:

```bash
pip install -r requirements-test.txt
python -m pytest tests -q
node tests/test_dashboard.cjs
python ml/scripts/check_submission.py ml/outputs/submission.csv
uvicorn app.main:app --app-dir backend --port 8000
```

В другом терминале:

```bash
python docs/performance/tests/smoke_test.py --base-url http://127.0.0.1:8000
python docs/performance/tests/load_test.py --scenario typical --requests 200 --concurrency 10
```

Для обучения и обработки нужны исходные файлы: инструкции в [ML README](../ml/README_ML.md) и [README обработки](../data_preparation/README.md).

## Границы проверки

- Многогигабайтные транзакции не пересчитывались целиком. Обработка использует готовые labels; отдельная функция полной сверки описана в README обработки.
- Историческая копия `docs/performance/app/` сохранена для происхождения нагрузочных результатов. Исправления относятся к основному `backend/`.
- Chart.js, Leaflet, Swagger и картографические тайлы требуют внешних ресурсов; полностью автономный режим не проверялся.
- Leaderboard повторно не оценивался. Проверено точное воспроизведение уже выбранного submission.
- Тестовая библиотека Starlette выдаёт предупреждение об устаревании интеграции с httpx; тесты проходят.
